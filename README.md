# TDA Mox — Local ADB Shell & Wireless Debugging Terminal

**TDA Mox** is a modern Android terminal application designed to establish a direct **Local ADB Shell** environment on-device using **Android Wireless Debugging**.

It provides a native terminal interface to execute Android system commands, shell scripts, and Toybox utilities directly without needing an external PC or ADB host.

---

## Key Features

- **Local ADB Shell Terminal:** Executes commands directly within the local system shell context.
- **Wireless Debugging Pairing:** Seamless local ADB setup using Android's native Wireless Debugging protocol.
- **Shizuku Compatibility:** Works alongside Shizuku execution contexts for permission-elevated tasks.
- **Full Toybox Utility Support:** Run system diagnostics and shell commands directly on-device.

---

## Practical Applications

TDA Mox is designed for power users, security research, and Android automation:

- System inspection and process monitoring (`ps`, `top`, `dumpsys`)
- Package and component management (`pm`, `am`, `cmd`)
- System property tweaks (`getprop`, `setprop`)
- File system inspection and automation using Toybox utilities
- Custom local shell scripting and environment configuration

---

## Compatibility

Optimized for modern Android versions operating with native Wireless Debugging:

- Android 14
- Android 15
- Android 16
